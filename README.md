# Digital Business Studio

The public storefront of James's shop in [PAPERWORLD](https://mr-tanq.github.io/paperworld/):
small, original digital products with secure Stripe checkout and instant download.

- Catalogue: `products.json` · Shop page: `index.html` · After payment: `thanks.html`
- Sellable files are **never** stored here; they live in private storage and are delivered by a
  short-lived personal link after the payment is confirmed.
- `npm test` runs the catalogue and storefront checks.
